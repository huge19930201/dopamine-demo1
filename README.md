# 多巴胺越狱插件示例（iOS 16，rootless）

这是一个**零基础也能用**的示例：上传到 GitHub 后，由 GitHub 的云服务器自动编译，
产出 `.deb` 文件，装到已多巴胺越狱的 iPhone 上就会弹出一个"编译成功"提示框。

## 你只需要做的事情（全程不用写代码）

### 第 1 步：注册 GitHub 账号
打开 https://github.com ，用邮箱免费注册一个账号。

### 第 2 步：新建一个仓库
1. 登录后点右上角 `+` → `New repository`
2. 仓库名随便起，例如 `dopamine-demo`
3. 选 `Public`（免费额度够用）或 `Private` 都行
4. 不用勾选任何初始化选项，直接点 `Create repository`

### 第 3 步：把本文件夹里的文件全部上传
1. 在仓库页面点 `Add file` → `Upload files`
2. 把本地的这些文件和文件夹一起拖进去上传：
   - `Makefile`
   - `Tweak.x`
   - `control`
   - `.github` 文件夹（这个很重要，里面是自动编译配置）
3. 拉到底点 `Commit changes` 提交

> 注意：`.github` 是隐藏文件夹，上传时要确认它也一起传上去了。

### 第 4 步：等它自动编译
1. 提交后，点仓库顶部的 `Actions` 标签
2. 你会看到 `Build Dopamine Tweak` 在运行，等几分钟
3. 出现绿色 ✓ 就说明编译成功

### 第 5 步：下载编译结果
1. 点进刚才那次运行记录
2. 拉到页面最底部，找到 `Artifacts` → `tweak-deb`
3. 下载这个 zip，解压后得到一个 `.deb` 文件

### 第 6 步：装到手机
1. 把 `.deb` 传到已越狱的 iPhone（用 AirDrop 隔空传送，或微信/邮件发给自己）
2. 用手机上的 **Sileo**（多巴胺自带）打开这个 `.deb` 并安装
3. 安装后点 `Respring`（注销桌面），锁屏再解锁，约 3 秒后弹出"编译成功"提示框

## 之后想改功能？
告诉帮你做这个项目的人你想实现什么（比如改某个 App、改状态栏、加设置项），
改好 `Tweak.x` 重新上传，GitHub 会自动重新编译。
